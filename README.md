# Démonstration Relais

Questionnaires partagés par lien et QR code, suivi des réponses en trois colonnes, fiches contact sans doublon.
Démonstration sans serveur : personnes et données inventées, gardées dans le navigateur de chaque visiteur.

Le générateur de QR code (`vendor/qrcode.js`) est celui de Kazuhiko Arase, sous licence MIT.
